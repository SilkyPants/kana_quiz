# Kana Quiz Master (かなクイズ)

A cross-platform Flutter application for testing and practicing Japanese Hiragana and Katakana, targeting Desktop and Web.

## Features

- **Full Kana Coverage**: Complete sets of both Hiragana (71 symbols) and Katakana (71 symbols), including Gojūon, Dakuten, and Handakuten.
- **Interactive Practice**: Randomly cycles through chosen symbols; type Romaji readings and submit with `Enter`.
- **Accurate Scoring & Review**: Instant accuracy percentage and itemized breakdown of correct vs typed answers.
- **Responsive Multi-Column Design**: Automatically organizes symbol rows into 2 or 3 columns on desktop and wide screens.
- **Customizable Theming**: Beautiful `#7D5BA6` theme supporting Light, Dark, and System modes.

## Getting Started

### Prerequisites
- Flutter SDK 3.10+
- Chrome, Edge, or Windows build tools

### Running the App
- **Windows Desktop**:
  ```bash
  flutter run -d windows
  ```
- **Web (Edge/Chrome)**:
  ```bash
  flutter run -d edge
  ```

### Running Tests
```bash
flutter test
```
